Midifier: Any strings of words, numbers and more... into usable midi!

Aim for prototype:
Allow for an input of any kind into the program, interface with the midi specs, 
and output a midi file for testing.

Full Midifier Feature List:
cli, with input and output
--config for modifying the Key used, the bpm, and more!
Algorithm for randomising velocity, offset timing, and more! (configurable)

C Features that will be used:
Main function arguments,
file i/o,
loops and iteration through data,
malloc,
json manipulation (Will use library)
and more...
